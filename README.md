# 🍳 A Cozinha do Brito

A **Cozinha do Brito** é um projeto que nasceu em 2022, quando Lucas Brito começou a estudar HTML e decidiu criar um espaço para reunir suas receitas favoritas.

O que começou como um pequeno site de aprendizado se transformou em um catálogo de receitas, agora com uma nova identidade visual, páginas individuais, ingredientes, modos de preparo, dicas e pesquisa para facilitar a busca por pratos.

Mais do que um site de receitas, é um projeto que acompanha a evolução de quem o criou.
